# Flood-risk screening for emergency medical services

Code accompanying the manuscript:
"Screening flood-risk exposure for emergency response"

## Analysis
`ambulance_flood_screening.py` contains the main analysis workflow used to:
- calculate ambulance response routes;
- assess historical route exposure to Daily Flood Index (DFI) conditions;
- perform the 2021 operational screening analysis; and
- run the sensitivity analyses reported in the manuscript.

The underlying ambulance dispatch data are confidential and are therefore not included in this repository.
